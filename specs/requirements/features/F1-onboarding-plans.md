# Onboarding plans

## Purpose

HR creates an onboarding plan for each new hire: their details, start date and the checklist of tasks across IT, HR and facilities.

## User Stories

- F1.1 As an HR coordinator, I create an onboarding plan for a new hire by entering their name, role, department, start date and manager.
- F1.2 As an HR coordinator, I start each plan from the standard checklist template, which copies its tasks into the plan.
- F1.3 As an HR coordinator, I add, edit or remove tasks in a hire's plan, each tagged IT, HR or facilities.
- F1.4 As an HR coordinator, I edit the standard template's tasks so future plans start from the updated checklist.
- F1.5 As an HR coordinator, I change a hire's start date and the plan's due dates shift with it.
- F1.6 As an HR coordinator, I see a list of all onboarding plans and open any one.
- F1.7 As an HR coordinator, I cancel a plan for a hire who will not join.

## Decisions

- There is one standard template, copied into each new plan; later template edits do not change existing plans.
- Each template task has a due date expressed as a number of days before or after the start date.
- The manager is recorded as a name on the plan only; the manager does not sign in.
